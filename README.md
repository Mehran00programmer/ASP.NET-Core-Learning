# آموزش ASP.NET Core

### معرفی پروژه

این مخزن با هدف انتشار آموزش‌ها، یادداشت‌ها و مثال‌های کاربردی در زمینه توسعه وب ایجاد شده است.

مطالب این مجموعه با تمرکز بر یادگیری مفاهیم، ارائه مثال‌های کاربردی و مستندسازی دانش برنامه‌نویسی تهیه می‌شوند.

---

### پیش‌نیازهای آموزش

برای درک بهتر مطالب این مخزن، آشنایی با سه حوزه زیر ضروری است.

**۱. زبان برنامه‌نویسی سی‌شارپ**

نام انگلیسی: ‎C#‎

- متغیرها و انواع داده
- عملگرها و دستورات شرطی
- حلقه‌ها و توابع
- آرایه‌ها و مجموعه‌ها
- کلاس‌ها و اشیا
- برنامه‌نویسی شیءگرا
- مدیریت خطاها و استثناها

**۲. توسعه سمت کاربر**

نام انگلیسی: ‎Front-End Development‎

- زبان نشانه‌گذاری صفحات وب: ‎HTML‎
- زبان طراحی صفحات وب: ‎CSS‎
- زبان برنامه‌نویسی جاوااسکریپت: ‎JavaScript‎
- مفاهیم پایه طراحی و توسعه صفحات وب

**۳. پایگاه داده و اس‌کیوال سرور**

نام انگلیسی پایگاه داده: ‎Database‎

نام سامانه مدیریت پایگاه داده: ‎SQL Server‎

- مفاهیم پایگاه داده رابطه‌ای
- جداول، ستون‌ها و رکوردها
- کلیدهای اصلی و خارجی
- دستورات پایه زبان ‎SQL‎
- ایجاد، خواندن، ویرایش و حذف داده‌ها
- ارتباط بین جداول
